# CPU-Schedulers

# Overview

This project is a Java-based simulation of several CPU scheduling algorithms, which are crucial for operating systems to manage processes effectively. The simulation includes implementations of both traditional and adaptive scheduling algorithms, focusing on optimizing process execution order, waiting time, and turnaround time.

# Features

Supported Scheduling Algorithms

1. Non-preemptive Priority Scheduling (with context switching)

2. Non-preemptive Shortest Job First (SJF)
    * Solves the starvation problem.

3. Shortest Remaining Time First (SRTF) Scheduling (with context switching)
   * Solves the starvation problem.

4. FCAI Scheduling (an adaptive algorithm):
     * Combines priority, arrival time, and remaining burst time into a composite FCAI factor.
     *  Features dynamic quantum allocation.
     * Addresses inefficiencies and starvation issues of traditional algorithms
